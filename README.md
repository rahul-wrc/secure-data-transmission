# FPGA-Based Secure Data Transmission Engine Using CRC-8 and Scrambler

## Project Overview

This project implements a digital data processing system using Verilog HDL. It combines an LFSR-based data scrambler and a CRC-8 error-detection module to demonstrate two important techniques used in digital communication systems.

The scrambler XORs input data with a pseudo-random sequence generated by an 8-bit Linear Feedback Shift Register (LFSR). The CRC-8 module processes incoming bytes to generate a checksum that can help detect transmission errors.

## Objectives

- Implement an LFSR-based data scrambler using Verilog.
- Generate an 8-bit CRC using polynomial `0x07`.
- Understand sequential logic, XOR operations, shift registers, and polynomial-based error detection.
- Simulate and verify RTL functionality using a Verilog testbench.
- Explore FPGA implementation using Xilinx Vivado.

## 1. Scrambler Module — `scrambler.v`

```verilog
module scrambler (
    input clk,
    input rst,
    input [7:0] data_in,
    output reg [7:0] data_out
);

    reg [7:0] lfsr;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            lfsr <= 8'hA5;
        end else begin
            lfsr <= {lfsr[6:0], lfsr[7] ^ lfsr[4]};
        end
    end

    always @(posedge clk) begin
        data_out <= data_in ^ lfsr;
    end

endmodule
```

### Working Principle

- An 8-bit LFSR generates a deterministic pseudo-random sequence.
- The initial LFSR seed is `8'hA5`.
- XOR feedback updates the LFSR state on every rising clock edge.
- The current LFSR state is XORed with the input data to produce the scrambled output.

**Equation:**

`Scrambled Data = Input Data XOR LFSR State`

XOR is reversible: XORing the scrambled data with the same synchronized LFSR sequence recovers the original data.

## 2. CRC-8 Module — `crc8.v`

```verilog
module crc8 (
    input clk,
    input rst,
    input [7:0] data_in,
    input valid,
    output reg [7:0] crc_out
);

    reg [7:0] crc;
    reg [7:0] d;
    reg [7:0] c;
    integer i;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            crc <= 8'h00;
        end else if (valid) begin
            d = data_in;
            c = crc;

            for (i = 0; i < 8; i = i + 1) begin
                if (c[7] ^ d[7])
                    c = (c << 1) ^ 8'h07;
                else
                    c = c << 1;

                d = d << 1;
            end

            crc <= c;
        end
    end

    always @(posedge clk or posedge rst) begin
        if (rst)
            crc_out <= 8'h00;
        else
            crc_out <= crc;
    end

endmodule
```

### Working Principle

- The internal CRC register initializes to zero.
- The `valid` signal enables processing of a new input byte.
- The module processes the eight input bits, starting with the most significant bit.
- The CRC state shifts left and conditionally XORs with polynomial `0x07`.
- The resulting CRC state is made available through the registered output.

**Generator polynomial:**

`G(x) = x^8 + x^2 + x + 1`

CRC is an error-detection mechanism, not an error-correction mechanism. A receiver must independently calculate and compare the CRC to detect data corruption.

module tb_scrambler_crc8;
